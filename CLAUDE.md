# CLAUDE.md — Presto / Trino Quickwit Connector

## Key Commands
- **Unit Tests:** `./mvnw clean test` (or `./mvnw test -pl ulak-presto-quickwit-connector`)
- **Docker Build & Push:** `./push.sh <version> <platform>` — `<platform>` needs a real platform string (`linux/amd64`); `both` only works as a Jenkins param. `prod=true`: override `prod_ip=192.168.109.203` for OGM.
- **Yucemonitoring:** `kubectl --kubeconfig ~/.kube/yucemonitoring.config -n yucemonitoring`, coordinator `maya-trino-multi-coordinator`. **OGM:** `ssh ulak@192.168.109.203` then `kubectl -n maya3`, coordinator `maya-trino-single-coordinator`. Both clusters' Trino container is `trino-coordinator`, not `trino`.
- **Patching a live ConfigMap:** `kubectl patch --type merge --patch-file <json>`, not `get -o yaml | sed | apply -f -` (the `last-applied-configuration` annotation JSON-encodes `data`; `sed` can corrupt its `\n` escapes).

## Architecture & Configuration
- **Multi-tier history routing:** `history-time-threshold-seconds` (also takes an explicit `minutes:seconds` pair) + `history-tiers` (CSV `minutes:thresholdSeconds`) in `quickwit.properties` pick the coarsest rollup index a query's range clears (`HistoryTier`/`HistoryIndexResolver`) — check the live ConfigMap, not this doc. `QwQueryRewriter.java` rewrites raw field names (`tx`) to rollup ones (`tx_max`) whenever `qwIndex` points at a history index, gated on `QwUtil`'s explicit `historyIndexActive` flag, not `historyIndex.equals(qwIndex)` (broke once tier escalation could derive a different `qwIndex`).
- **Custom JSON flattener** (`QwUtil.flattenJsonNode`/`arrangeAggregation`) parses Quickwit responses; column names don't match a static trace of the code — verify any fix by running it through Trino live. `arrangeAggregation()` only propagates a bucket's `key` into its leaf metric when that leaf's value is non-null, so a null metric silently loses its row's identity too, not just its value.
- **Rhino JS engine** gets native `Math` via scope injection.
- **Redis:** `QueryParameters.connectionId` scopes `RedisCacheWorker` per catalog — see [`ulak-presto-connector-base/CLAUDE.md`](ulak-presto-connector-base/CLAUDE.md). `ConnectorBaseUtil.select()` holds its Jedis connection across the whole downstream fetch, not just cache GET/SET — pool exhaustion traces back here (diagnosed, not fixed).
- **Image registries:** OGM/yucemonitoring's `maya-nexus:35000/...` are different physical registries — push each explicitly, `kubectl set image` by hostname not IP.
- **Quickwit:** metastore is Postgres-backed, independent of `qwdata` — clear orphaned splits via `PUT /api/v1/indexes/{id}/clear`. Rejects `"0"` as a datetime lower bound (use `"*"`). Hard-caps `max_hits`/`start_offset` at 10,000 — page past that by splitting on a low-cardinality field (e.g. per-site), not time, if a bucket's docs share one timestamp.
- **`../qw-rollup-engine`** populates the rollup indexes this connector reads. `tasks.json`: one `intervals: [15, 60]` list per task. Metrics tasks key site as `span_attributes.h`; flow tasks use `span_attributes.v` (no `h` at all) — don't assume `h` is universal.
