# CLAUDE.md — Presto / Trino Quickwit Connector

## Key Commands
- **Unit Tests:** `./mvnw clean test` (or `./mvnw test -pl ulak-presto-quickwit-connector`)
- **Docker Build & Push:** `./push.sh <version> <platform>` (`<platform>` needs a real value like `linux/amd64`; `both` is Jenkins-only) or trigger Jenkins job `maya-trino-platform` (`JENKINS_JOB_TRINO` in `.env`) directly. `prod=true` needs `prod_ip=192.168.109.203` for OGM; yucemonitoring builds use `prod=false`.
- **Yucemonitoring:** `kubectl --kubeconfig ~/.kube/yucemonitoring.config -n yucemonitoring`, coordinator `maya-trino-multi-coordinator`. **OGM:** `ssh ulak@192.168.109.203` then `kubectl -n maya3`, coordinator `maya-trino-single-coordinator`. Both clusters' Trino container is `trino-coordinator`. `ulak` has `docker`-group access on all 3 OGM nodes but not filesystem root.
- **Patching a live ConfigMap:** `kubectl patch --type merge --patch-file <json>`, never `get -o yaml | sed | apply -f -` (corrupts the `last-applied-configuration` annotation's escaped `\n`s).

## Architecture & Configuration
- **`raw_query(...)` TVF** (`RawQuery.java`, primary query surface — see `ulak-presto-quickwit-connector/CLAUDE.md`) needs **double-quoted argument names** (`"qwindex" => 'metrics3'`) or Trino uppercases them and the call fails. Its `aggs` DSL (`AggsDslCompiler`) now also supports `order=key[:dir]` and `missing="<v>"` (2026-09-04, sub-doc has detail).
- **Multi-tier history routing:** `history-time-threshold-seconds` (+ optional `minutes:seconds` pair) and `history-tiers` (CSV) in `quickwit.properties` pick the coarsest rollup index a query's range clears (`HistoryTier`/`HistoryIndexResolver`) — check the live ConfigMap, not this doc.
- **Custom JSON flattener** (`QwUtil.flattenJsonNode`/`arrangeAggregation`, `sqlversion=0`) — verify any fix live (`kubectl cp` + `trino -f`; multi-KB `--execute` strings get mangled). Grafana's trino-datasource plugin base32-encodes passthrough bodies in `system.runtime.queries.query`. `postProcessRows()`'s `replacefromcolumns` strip is a non-anchored substring removal — a bucket id that's numerically a prefix of a sibling (`"1"` vs `"11"`) can partial-match into a misleading residual key.
- **Redis:** `QueryParameters.connectionId` scopes `RedisCacheWorker` per catalog — see [`ulak-presto-connector-base/CLAUDE.md`](ulak-presto-connector-base/CLAUDE.md). `ConnectorBaseUtil.select()` holds its Jedis connection across the whole downstream fetch, not just cache GET/SET — pool-exhaustion root cause, priority in TOBEDECIDED.md.
- **Image registries:** OGM/yucemonitoring's `maya-nexus:35000` are different physical registries — push each explicitly (OGM → `192.168.109.204`). No OGM node has internet — mirror via `skopeo copy --dest-tls-verify=false --dest-creds admin:nexus2025! docker://<source> docker://192.168.109.204:35000/<repo>:<tag>`; same tool exports a portable tar via `docker-archive:<file>.tar:<repo>:<tag>`.
- **Quickwit:** metastore is Postgres-backed, independent of `qwdata` — `clear()` doesn't reclaim disk until the GC sidecar runs. Rejects `"0"` as a datetime lower bound (use `"*"`). Hard-caps `max_hits`/`start_offset` at 10,000. `aggregation_bucket_limit` (default 65000) is baked into OGM's image, not ConfigMap-adjustable.
- **`../qw-rollup-engine`** populates the rollup indexes this connector reads (Helm chart in `helm_repo1`, not `ai/anomaly`). `tasks.json`/`config.json` are ConfigMap-mounted, read once at startup — live ConfigMap, chart copy, and repo files can all disagree; diff before trusting any. Checkpoint backend resolves once at startup, no runtime fallback — status in TODO.md.
- **OGM's master node (`192.168.109.203`) repeatedly goes fully unresponsive** under heavy concurrent I/O — see `machine_ops`.
